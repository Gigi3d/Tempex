# Vendored subset of OpenZeppelin Contracts Upgradeable 5.4.0

Only the seven files TempexEscrow imports, directly or transitively, are kept
here, unmodified from the `v5.4.0` tag of
https://github.com/OpenZeppelin/openzeppelin-contracts-upgradeable (MIT, see
LICENSE). They pair with `lib/openzeppelin-contracts` at the same version.

To refresh: check out the tag and copy these same paths over. If a new import
appears, `forge build` names the missing file.
